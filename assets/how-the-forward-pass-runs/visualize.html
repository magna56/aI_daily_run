Query now. Reuse the index.

Q is what this token looks for, K is how a past token wants to be found, V is the payload you mix in. A feature is just one of those vectors. The KV cache keeps K and V so the next word does not rebuild the whole prefix.

Q · query

The lookup for the token you are writing now. One new row per decode step.

K · key

The index entry each past token published. Cached so you do not re-project it.

V · value

The payload mixed in after the soft join. Also cached, per layer and head.

Toy attention weights (4 tokens)

Softmax rows. A later layer just reads these mixed vectors — that is all “features” has to mean here.
